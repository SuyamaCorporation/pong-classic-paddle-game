# ポン クラシック パドル ゲーム

古典的なポンゲーム。AI 対戦（↑↓キーまたはマウス操作）。スコア・難易度調整・クラシックな Canvas 描画。

## 機能
- Canvas（800x500）によるクラシックな Pong 描画
- プレイヤー左パドル（↑↓キー / マウス / モバイルタップボタン）、AI 右パドル
- ボールの反射・加速・当たり角度による方向変化
- スコア表示（先に 11 点で勝利）
- AI 難易度スライダー（低/中/高）
- サーブフェーズ（スペース / クリックで開始）
- LocalStorage に最高連勝を保存

## 技術
- Vanilla JS + Tailwind CSS CDN
- Canvas 2D API
- localStorage
